Política de privacidad de ReciclAI

Última actualización: 7 de octubre de 2026

ReciclAI es una aplicación gratuita que ayuda a encontrar puntos de reciclaje cercanos en Chile. Esta página explica qué información utiliza la aplicación, para qué fines, y qué no hace con ella.

Qué información utiliza la aplicación

  • Ubicación (GPS). Se utiliza únicamente para mostrar al usuario los puntos de reciclaje más cercanos a su posición, o dentro de un radio de 3 km si activa esa opción. La ubicación se envía al servidor solo en el momento de realizar la búsqueda — no se almacena asociada al usuario ni a su dispositivo, y no se genera ningún historial de ubicaciones.

Qué no hace la aplicación

  • No requiere cuenta ni inicio de sesión. ReciclAI no tiene sistema de usuarios: no se conoce la identidad de quien la usa, ni se almacenan nombre, correo electrónico o número de teléfono.
  • No incluye publicidad. La aplicación no muestra anuncios ni está integrada con redes publicitarias.
  • No utiliza herramientas de analítica o rastreo de terceros. No incluye Google Analytics, Firebase Analytics, Meta/ Facebook SDK, ni herramientas similares.
  • No vende ni comparte datos con terceros con fines comerciales o publicitarios.

Servicios de terceros que utiliza la aplicación

Para funcionar, la aplicación se conecta a los siguientes servicios, cada uno de los cuales recibe solo la información necesaria para cumplir su función:

  • Servidor propio de ReciclAI (alojado en Render), que mantiene la base de puntos de reciclaje y responde a las búsquedas por ubicación o por comuna. No conserva la ubicación del usuario después de responder la búsqueda.
  • OpenFreeMap (openfreemap.org), que provee los mapas que se muestran en la aplicación (basados en datos de OpenStreetMap). Al desplegar el mapa, el dispositivo solicita directamente las imágenes del mapa a ese servicio — práctica estándar en cualquier aplicación con mapas, equivalente a cargar una página web convencional.
  • La aplicación de navegación que el usuario elija (Google Maps, Waze o Apple Maps, según lo que tenga instalado). Al tocar "Ruta", se envía la dirección del punto de reciclaje a esa aplicación para trazar el camino — una vez abierta, se rige por su propia política de privacidad.

Permisos que solicita la aplicación

  • Ubicación ("mientras se usa la aplicación"): para mostrar los puntos cercanos a la posición del usuario. La aplicación puede utilizarse sin otorgar este permiso, seleccionando la comuna manualmente.
  • Internet: para solicitar los puntos de reciclaje y cargar el mapa.

Menores de edad

ReciclAI no está dirigida específicamente a niños ni niñas, y no recolecta información que permita identificar a una persona, de ninguna edad.

Cambios a esta política

Si esta política cambia, la fecha indicada al inicio de esta misma página se actualizará en consecuencia. Se recomienda revisarla periódicamente.
